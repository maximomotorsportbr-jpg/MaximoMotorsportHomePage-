# Máximo Motorsport

Site institucional desenvolvido para a **Máximo Motorsport**, oficina especializada em UTVs, manutenção, preparação e projetos automotivos.

🌐 **[Acessar o site](https://maximomotorsportbr-jpg.github.io/MaximoMotorsportHomePage-/)**

O projeto foi desenvolvido com foco em **simplicidade, responsividade, performance e experiência do usuário**, utilizando tecnologias web nativas.

## Sobre o projeto

O site apresenta os serviços oferecidos pela Máximo Motorsport, informações sobre a empresa, projetos realizados, diferenciais e formas de contato.

Entre as principais funcionalidades:

* Página institucional responsiva
* Seção de serviços com carrossel infinito
* Carrossel com interação por mouse e toque
* Galeria de projetos
* Modal para visualização ampliada das imagens
* Vídeo de apresentação no Hero
* Links para WhatsApp e Instagram
* Layout adaptado para desktop e dispositivos móveis
* Animações e interações utilizando JavaScript
* Imagens otimizadas em WebP

## Tecnologias

* HTML5
* CSS3
* JavaScript
* WebP
* Git
* GitHub Pages

## Performance

Durante o desenvolvimento, também foram realizados testes de performance para identificar recursos que poderiam impactar o carregamento da página.

A partir da análise do carregamento, foram realizadas otimizações como:

* Conversão de imagens para WebP
* Lazy loading nas imagens
* Otimização do carregamento de recursos
* Ajustes no carregamento do vídeo
* Redução de recursos desnecessários


## Responsividade

O site foi desenvolvido para funcionar em diferentes tamanhos de tela, com adaptações específicas para dispositivos móveis.

O layout utiliza CSS responsivo para adaptar:

* Navegação
* Galerias
* Cards
* Carrosséis
* Seção institucional
* Botões de contato
* Conteúdo da página

## Objetivo

O objetivo do projeto foi criar uma presença digital para a Máximo Motorsport utilizando uma solução simples e de fácil manutenção, sem a necessidade de frameworks.

Por se tratar de um site institucional, a utilização de **HTML, CSS e JavaScript puro** permite manter o projeto leve, simples e adequado à sua finalidade.
